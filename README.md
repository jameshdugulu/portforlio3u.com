# Personal Portfolio Website

This is a personal portfolio website showcasing projects, skills, and contact information for James Hallie Dugulu.

## Description

The website is built with HTML, CSS, and a little JavaScript. It includes the following sections:

*   **Home:** An overview of skills and roles.
*   **About:** More detailed information about James.
*   **Projects:** A showcase of completed projects.
*   **Contact:** A way to get in touch.

## How to View

1.  Clone or download this repository.
2.  Navigate to the repository's root directory.
3.  Open the `Home.html` file in your web browser to view the website.

## Structure

*   `.html` files: Contain the content for each page.
*   `main.css`: Main stylesheet for general site styling.
*   `About.css`: Specific styles for the About page.
*   `code.js`: Contains JavaScript for site interactions (e.g., mobile menu).
*   `icon/`: Directory for images and icons used on the site.

## Customization

Feel free to update the content in the HTML files (especially `Project.html` and `Contact.html` placeholders) and modify the CSS to personalize the portfolio.
